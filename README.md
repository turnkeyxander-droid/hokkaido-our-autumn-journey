# Hokkaido · Our Autumn Journey

私人北海道旅行手册的 Day 1–2 原型，采用 Next.js、TypeScript 与 Tailwind CSS。网站为手机优先设计，包含首页、Day 1、Day 2、每日内嵌地图及 Google Maps 导航按钮。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 `http://localhost:3000`。

## GitHub Pages

推送到 `main` 后，GitHub Actions 会自动构建并发布静态网站：

`https://turnkeyxander-droid.github.io/hokkaido-our-autumn-journey/`

如果首次部署没有自动启用，请到仓库 **Settings → Pages → Build and deployment**，将 Source 设为 **GitHub Actions**，再重新运行工作流程。

## 内容说明

- 行程内容仅来自原始 Day 1–2 攻略截图。
- 没有补写未提供的真实坐标或官方 URL。
- Google Maps 使用地点名称进行搜索与导航。

> 这是公开仓库与公开网站，行程日期和住宿名称会对所有访问者可见。
